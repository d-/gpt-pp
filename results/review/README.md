# The reviewer's short runs

Scripts and logs of the independent review of the experiments ([docs/REVIEW.md](../../docs/REVIEW.md)), kept as
they were run on the lab's machine (the paths in the scripts are that machine's). Each run directory holds the
run's configuration, its log and its console output. They are short (10M to 16M tokens) and were made to test one
suspicion each; the runs that the series reports were made again in full and are under [results/runs](../runs)
(`opt-adamw-own-*`, `warm-2019-small-*`, `swap-pos-sinusoidal-after-norm`, `split-rung7-adamw-*`).
